## 采集条件

- **OLED**：上位机镜像推流抓图，128×128 单色，放大 8 倍保存为 1024×1024
- **SCPI**：8 个解析点 × 5 类输入 = 40 条（正常值 / 下边界 / 上边界 /
  非数值串 / 空参数）
- **SYNC**：示波器余晖显示，触发约 10 次；**无源探头 + 接地夹**

## 结论

### 1. SCPI 响应 —— 逐字节完全一致 ✅

两份 txt 的 SHA-256 相同。这验证了：

- **批次 15**（`atoi`/`atof` → `strtol`/`strtod`）：行为严格保持，包括
  "非法输入返回 0"的既有容错语义
- **批次 8**（全大写变量改名）、**批次 5**（extern 集中化）

值得特别指出：这 40 条里**包含了 `PWM:PER:NAN`、`LPWM:PER:INF` 与
`PULS:WIDTH:ABC`** —— 前两者正是 `atof` 与 `strtod` 可能分歧的高风险输入
（NaN/Inf 解析），后者是"非法输入返回 0"的典型。三者响应均一致。

### 2. OLED 逐页镜像 —— 12 对中 10 对逐字节一致 ✅

按页面序号 `_002`~`_013` 配对（两边页型完全对应），其中 10 对 **SHA-256 相同**。
这验证了 **批次 14**（绘图 API 坐标形参由 `int16_t` 加宽为 `int`）没有改变任何
绘制数值。

**2 对存在差异**：`_012`（NPULSE）与 `_013`（COMPPWM）。差异经像素级分析定位为：

- 只出现在 OLED 坐标 **x84~119, y3~9** 这一小块（占全屏 0.5~0.65% 的像素）
- **该区域的边框完全一致，只有框内文字在水平方向错开了 1~5 像素**
- 全局与局部的平移搜索都无法用"整块位移"解释 —— 因为移的是**文字**，不是框

判定为 **WouoUI 自动滚动字符串的滚动相位差**：文本超出框宽时横向滚动，相位
取决于进入页面后经过的时间；两次抓图相隔一小时、跨两个运行会话，相位自然不同。

> **这个判定尚未做决定性验证。** 若要坐实，只需抓同一页面**连续两次**：
> 若两次也出现同样的文字错位，即为滚动相位；若两次完全一致，则需要重新
> 怀疑 `WouoUI_CanvasDrawSlideStr`（批次 14 改过它的 `y` 形参）。

### 3. SYNC 对齐 —— 抖动无变化 ✅（但有测量学注意点）

两张截图**哈希不同，这是预期的**：余晖显示累积的是随机抖动的采样，两次抓图
不可能像素相同。

目视结论：**抖动分布无变化**；但 **SYNC 过冲后的振铃频率两次不同**。

原因判定为**测量方法而非固件**：使用无源探头 + 接地夹，两次测量的**地线回路
面积不同**，而接地引线电感直接影响振铃频率。这属于典型的探头引入差异。

> 若要严格比对振铃，需改用**弹簧地针**（短接地）并固定探头位置与走线。

## 补充记录：N 脉冲间隔复测（未存图）

批次收尾时发现并修正了一处**既有的**标定偏差，数据以文字记录于此：

现象：设定间隔普遍偏长约 70ns。补偿常量 `NPULSE_INTERVAL_COMP_US` 由 `0.9`
重新标定为 `0.97`（依据五点实测，反推开销五点下界全部落在 0.96，跨多个分频档
无漂移 → 证明开销是与分频档无关的恒定时间量）。

| 设定 | 改前实测 | 改后实测 |
|--:|:--|:--|
| 1 µs | 1.06 ~ 1.12 | 1.005 ~ 1.045 |
| 2 µs | 2.06 ~ 2.10 | 1.98 ~ 2.00 |
| 4 µs | 4.06 ~ 4.10 | 3.98 ~ 4.02 |
| 8 µs | 8.06 ~ 8.07 | 7.99 ~ 8.01 |
| 16 µs | 16.07 ~ 16.09 | 15.98 ~ 16.01 |

改后 2/4/8/16µs 的中心残差均 ≤10ns，远小于 20~40ns 的抖动展宽 —— 已无可检测的
系统性偏差，剩余误差全部来自中断响应抖动。1µs 点中心 1.025 = 下限钳位 0.05 +
开销 0.975，与模型吻合。

## 如何复现

```bash
git checkout fbbc384          # 采基线
cmake --build build/Debug     # 烧录后按上述条件采集

git checkout code-hygiene     # 采改后
cmake --build build/Debug
```

比对方法（本目录的结论即由此得出）：

```bash
# SCPI: 直接比字节
cmp baseline_fbbc384/0-5_scpi_responses.txt after_code-hygiene/2-1_scpi_responses.txt

# OLED: 按页面序号配对后比字节
for i in $(seq -w 002 013); do
  cmp baseline_fbbc384/0-4_oled_pages/*_${i}.png \
      after_code-hygiene/1-3_oled_pages/*_${i}.png && echo "$i 一致"
done
```

> 注意：**不要对 OLED 抓图做任何重编码**（PNG 优化、格式转换、缩放）—— 逐字节
> 一致性本身就是证据，重编码会破坏它。
